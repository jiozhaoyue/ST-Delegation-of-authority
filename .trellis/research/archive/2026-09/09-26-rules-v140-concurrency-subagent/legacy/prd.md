## Requirements

### R1 — `L0-7` 扩写：多会话共享工作区的提交边界（MUST）

在 `rules/L0-global.md` 的 `L0-7` 内新增一节，至少覆盖：

- **R1.1 提交只用显式 pathspec**：`git add <具体文件>`；**禁止 `git add -A` / `-u` / `.`**。
  原因：本机多个 Claude Code 会话共享同一批工作区，`-A` 会捎带其他会话的在途改动（N-14 实证）。
- **R1.2 暂存区校验**：`git commit` 前 `git diff --staged --name-only` 必须**恰为目标文件集合**，否则中止。
- **R1.3 块内特例只落「项目覆盖」节**：目标仓要写本仓例外时，落块的 `## 项目覆盖` 节（`PO-N`），
  **不写规则块正文**——正文会被下次重建抹掉（N-13 实证）。
- **R1.4 写盘前先看漂移**：跑 `sync_tavern_rules.py --apply` 前先 `--verify`；
  漂移项若在 `agent_files_ignored: true` 的仓（`ST-chatfilesys-rebuild`、`ST-git-improve`），
  **脏工作区门禁对它们失效**（文件被 `.gitignore` 忽略 → `git status` 看不见）→ 必须人工确认是不是有意手改。
- **R1.5** 对应更新 `L0-7` 的「原因」与「违反后果」，并把 N-13/N-14 作为证据写入（**只写事实与机制，不写本机绝对路径**——P-17 纪律）。

### R2 — `L0-8` 重写：子代理使用纪律（MUST）

用户 2026-09-26 裁定后的口径：

- **R2.1 删除写死模型**：删掉「当前指定 `DeepSeek-V4-Flash[free]`（模型 ID `claude-haiku-4-5-20251001`）」与「禁止使用 Kimi K3 做子代理」两处。
  （依据：自写子代理模型门禁已按用户裁定在任务 D 中删除，`L0-8` 的模型指定已无任何执行装置。）
- **R2.2 用前停下询问用户指定模型/代理**：规则不再指定模型；每次要用子代理前**必须停下向用户确认用哪个模型/代理**（用户本轮已预先指定者除外）。
- **R2.3 声明用途 = 并发提速**：子代理的**首要目的是并发地推进任务以节省时间**；
  **上下文隔离是次要收益**。规则须写明「必须保证时间上的净收益」——若开子代理反而更慢则不开。
- **R2.4 宿主前置条件（阻塞式则不开）**：使用前必须**核实当前宿主的子代理是"非阻塞/可并发"**；
  若宿主子代理是**阻塞式**（典型：必须等全部子代理完成才能读取结果并继续，如 Copilot），
  **则不开子代理**，改为向用户说明该限制并**询问用户要求**。
- **R2.5 保留两条有效经验**：并发上限（本机实测免费端点 6 并发即 `502` 熔断 → 上限 3；同时受宿主上限约束）、
  子代理任务必须**自包含**（明确检索范围、具体问题、期望输出）、失败时**先落盘部分结果再重试**。
- **R2.6 附依据（可复核事实）**：规则内引用当前宿主（Claude Code）的**子代理能力事实**并标注公开文档出处：
  - **模型可指定**：逐次调用可传 `model`；解析顺序 = 逐次参数 > agent 定义 frontmatter `model` > `CLAUDE_CODE_SUBAGENT_MODEL` 环境变量 > 主对话模型；可选值 `sonnet` / `opus` / `haiku` / `fable` / 完整模型 ID / `inherit`。
  - **非阻塞可得**：前台子代理阻塞主对话；**后台子代理与主对话并发**，交互式会话（fork 模式默认开）走后台；`CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` 会把子代理**强制变回前台阻塞**——此开关开启时按 R2.4 处理。
  - **并发上限**：默认 20 个并发子代理（`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` 可调）；嵌套深度默认 3 层。
  - 出处：Claude Code 官方文档 <https://code.claude.com/docs/en/sub-agents>（2026-09-26 核对）。
- **R2.7** 条目标题相应调整（现行标题「子代理模型与并发纪律」已不准确）。

## 实施中发现的额外事项（记账修正）

- **`README.md` 的 L0 条数过时**：写「15 条」，实测 **17 条**（L0-1…L0-17）→ 本任务顺手修正。
- **`rules/**` 未纳入 `.gitattributes` 的行尾锁**：仓库内为 LF、工作区为 CRLF（`core.autocrlf=true`）。
  同步器 `read_text` 会归一化，故**不影响分发结果**；但与其他「字节级契约」路径不一致。
  → **本任务不改**（属独立议题，留作候选条目）。
- **同步器解析边界是硬约束**：`OVERRIDE_HEAD = "## 项目覆盖"` 是块的拆分标记，
  **规则正文里不得出现与该标题逐字相同的字符串**——首版措辞踩中此坑，被回归测试 T 项「「项目覆盖」标题唯一」拦下，
  已改为「块末尾的『项目覆盖』节」。**这条约束值得写进 `docs/skills.md` 或同步器文档**（本任务只在 L0-7 正文里点明）。
